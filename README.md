## Install

**Downloader code: `2307851`** (or open aftv.news/2307851)

Open the **Downloader** app on your TV, enter the code and press **Go**, then install. You can also type this link instead:

```
https://github.com/raad113/NuvioTv-Clean/releases/latest/download/NuvioTv-Clean.apk
```

The code always gets the newest build, and new builds install over the old one without losing your settings.

## Features

**Automatic skipping.** Scenes flagged by the community are skipped as you watch, and strong language is muted. A short notice tells you each time something was left out.

**Your own limits.** Set nudity, sexual content and kissing, violence, language, drugs and frightening scenes to Off, Low, Medium or High.

**Subtitle muting per profile.** Each profile can mute any line whose subtitle contains English or Arabic swear words, plus words it adds.

**One button to share.** Press ♥ in the player when a scene starts and again when it ends. That's all.

**Safe from bad timings.** A scene shared by one person shows as an "unconfirmed" skip button until a second viewer confirms it, so nobody can make you miss part of a film.

**Ready to use.** The CleanStream add-on, with clean tags and digital-release dates on posters, and a family collection are added on first start. Nuvio account sign-in works as usual.

All [NuvioTV Reshaped](https://github.com/DavidVamaiotu/NuvioTV-Reshaped) features are included. Settings are under **Settings > Integrations > NuvioTv-Clean**.
